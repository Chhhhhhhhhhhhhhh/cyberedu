# 内容改造路线图（菜鸟教程式渐进改造）

> 目标：把"学习中心"52 章改造成**像菜鸟教程一样循序渐进**的风格——大白话、小步快跑、每个概念立刻跟一个能跑的例子、每章有动手练习。本文件记录风格规范与分批计划，改造按批次推进，每批一个模块。

## 背景与现状（2026-08-28 审计结论）

- 多数章节仅 4-9KB（≈2-4 千字），概念密度高、例子少，零基础读者跟不上
- 章节缺少"你会学到 / 跟着敲 / 练习 / 小结"的固定结构
- 模块顺序已修复：编程 → **网络** → 密码学 → Web → 渗透 → 恶意软件 → CTF（消除"密码学先讲 TLS、网络后讲 HTTP"的依赖倒置，并与首页学习路径一致）
- CTF 挑战已按类别轨道 + 难度递增重排（v2.6.1）

## 风格规范（每章必守）

以重写后的 `prog-01-02（控制流与函数）` 为标杆模板：

1. **开篇三件套**：一段大白话说清本章解决什么问题 + "本章你将学会"清单 + 声明无需安装环境
2. **小步推进**：概念按"第 N 步"编号，每步只引入一个新概念
3. **例子三连**：最小代码（完整可复制）→ 运行结果 → 逐行/逐要素拆解
4. **安全场景串联**：每个概念尽量用安全场景举例（端口、密码、状态码、日志），让读者知道"学这个干什么用"
5. **坑位提示**：callout（info/warn/success/safety）至少 2 个，含常见错误
6. **动手练习 ≥3 道**：用 `<details>` 折叠答案，先做再看
7. **章末小结表 + 下一章预告** + 相关练习/挑战跳转按钮
8. **篇幅底线**：正文 ≥ 12KB（约 5 千字），例题 ≥ 6 个可运行片段
9. 代码块统一 `<div class="code-block"><div class="copy-btn">复制</div><pre><code class="language-python">`；代码内 `<` `>` `&` 转义
10. 术语第一次出现给一句人话解释；避免未解释的英文缩写
